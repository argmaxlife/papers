# Gated Attention for Large Language Models：论文阅读笔记

> **论文**：Zihan Qiu 等，*Gated Attention for Large Language Models: Non-linearity, Sparsity, and Attention-Sink-Free*，arXiv:2505.06708v1（2025）。  
> **原文**：[arXiv:2505.06708](https://arxiv.org/abs/2505.06708)  
> **关键词**：Transformer、softmax attention、sigmoid gate、稀疏性、attention sink。

## 一句话概括

作者系统比较注意力层中不同位置和形状的门控方式，发现最有效的简单改动是在 scaled dot-product attention（SDPA）输出后加一个由当前 token 状态生成的、按注意力头区分的 sigmoid 门控。它在 attention 内部增加非线性，并以输入相关的稀疏分数筛选当前 query 的上下文输出；实验中该方法改善语言模型指标和训练稳定性，显著减少首 token attention sink，也提升长上下文扩展表现。

## 标准多头注意力回顾

设输入隐藏状态为 `X: [B,T,d]`，其中 `B` 是批大小、`T` 是序列长度、`d` 是模型宽度。Q、K、V 是线性投影并按头拆分后的张量。忽略 batch 维时，单个 query head 的 SDPA 为：

$$
S_{ij}^{(a)}=\mathrm{softmax}_j\!\left(\frac{q_i^{(a)}(k_j^{(a)})^\top}{\sqrt{d_k}}\right),\qquad
y_i^{(a)}=\sum_{j=1}^{T} S_{ij}^{(a)}v_j^{(a)}.
$$

`S` 的形状为 `[B,H_q,T,T]`，每行沿 key 位置 `j` 归一化；单头输出 `y` 为 `[B,H_q,T,d_k]`（常见实现排列也可能是 `[B,T,H_q,d_k]`）。多头输出拼接后经 `W_O` 投影回模型宽度 `[B,T,d]`。

## 核心门控公式与张量形状

论文把门控抽象为式 (5)：

$$
Y'=g(Y,X,W_\theta,\sigma)=Y\odot\sigma(XW_\theta).
$$

`Y` 是被调制的张量，`X` 是生成门控分数的另一份输入，`W_θ` 是可学习投影，`σ` 是激活函数，`⊙` 表示逐元素相乘。主方法在 SDPA 之后（图中的 `G1`）使用 sigmoid：

$$
\widetilde{Y}_{b,t,a,r}=Y_{b,t,a,r}\,\sigma\!\left((X_{b,t}W_\theta)_{a,r}\right),
\qquad \sigma(z)=\frac{1}{1+e^{-z}}.
$$

其中 `X` 取 attention 子层预归一化后的隐藏状态。门控分数依赖 token 位置 `t`，也依赖 query head `a` 和 head 内维度 `r`。对每个特征分量，sigmoid 输出在 `(0,1)`，因而保留或衰减对应的 SDPA 输出，不会像 ReLU 那样把正负方向翻转。

### 具体例子：GQA 的逐维 head-specific gate

取 `B=2, T=3, d=32, H_q=4, H_kv=2, d_k=8`。GQA 中 4 个 query heads 共享映射到 2 个 KV heads，但 SDPA 仍对每个 query head 产生独立输出：

```text
X (pre-norm hidden states)      [2, 3, 32]
Y (SDPA output, query heads)    [2, 3, 4, 8]
W_theta for elementwise G1      [32, 4*8] = [32, 32]
X @ W_theta                    [2, 3, 32]
reshape gate logits            [2, 3, 4, 8]
sigmoid gate                    [2, 3, 4, 8]
Y * gate                        [2, 3, 4, 8]
concat heads                    [2, 3, 32]
output projection W_O           [2, 3, 32]
```

例如位置 `t=2` 的某个 head 输出为 `Y=[0.8,-1.2,0.3,...]`，门控为 `g=[0.1,0.9,0.4,...]`，乘积为 `[0.08,-1.08,0.12,...]`。门控针对每个当前 query 的 head 输出，而不是对所有位置使用同一组静态缩放因子。论文表 1 的 G1 elementwise 形式每 token 产生 `H_q×d_k` 个分数；headwise 变体则每个 query head 仅产生一个分数，形状为 `[B,T,H_q,1]`，广播到该头的 `d_k` 维。

注意：门控乘在 SDPA 加权求和之后，所以它不改变 `S=softmax(QKᵀ/√d_k)`，也不直接重新分配某一行注意力概率。它缩放的是该 query 从上下文读出的向量。由于分数由 `X_{b,t}` 产生，这是 query-dependent gate；不是按 key/value token 固定筛选。

## 门控为什么增加表达力

论文式 (6) 将第 `i` 个 token、第 `a` 个头的输出写为：

$$
o_i^{(a)}=\sum_j S_{ij}^{(a)}X_jW_V^{(a)}W_O^{(a)}.
$$

其中 `W_V: [d,d_k]`、`W_O: [d_k,d]`（省略头拼接记号），二者合起来是经过 `d_k` 维瓶颈的低秩线性映射。对 GQA，多个 query head 还共享 KV 投影，表达受限更明显。若只把 `W_VW_O` 合并成一个矩阵，注意力输出就是对上下文表示做加权后，再做线性变换。

在 SDPA 输出处加门控，相当于在两个投影之间加入非线性映射（论文式 (8)）：

$$
o_i^{(a)}=\mathrm{GateMap}\!\left(\sum_jS_{ij}^{(a)}X_jW_V^{(a)}\right)W_O^{(a)},
$$

而在 V 投影后加门控（位置 `G2`，论文式 (7)）对应：

$$
o_i^{(a)}=\sum_jS_{ij}^{(a)}\,\mathrm{GateMap}(X_jW_V^{(a)})W_O^{(a)}.
$$

`G1` 的门控以当前 query `X_i` 生成，作用在聚合后的 `[B,T,H_q,d_k]`；`G2` 则以各 key/value 位置的状态生成门控，先调制 `[B,T,H_{kv},d_k]` 的 V，再被多个 query 聚合。作者发现两者都能补充非线性，但 `G1` 效果更好，进一步分析认为其门控具有更强的 query 相关稀疏性。门控若放在最终 `W_O` 之后（`G5`），就没有在 `W_V` 与 `W_O` 之间插入非线性，收益很小。

## 稀疏性与 attention sink

sigmoid 门控不是 hard top-k，也不保证分数恰好为零。论文说的“稀疏”是大量分数接近 0，使门控后的注意力输出中更多维度非常小。输入相关的门控可以根据当前 query 抑制无关上下文。作者的分析中，SDPA elementwise gate 的平均 gate score 约 `0.116`，headwise gate 约 `0.172`；跨 head 共享的 elementwise gate约 `0.271`，稀疏性较弱且效果较差。将 sigmoid 换为 `NS-sigmoid(x)=0.5+0.5 sigmoid(x)` 会把分数限制在 `[0.5,1]`，保留非线性但削弱抑制能力，表现也退化。

attention sink 指因果语言模型中，许多 query 把不成比例的注意力分配给序列开头的 token。作者在其基线中测得平均约 46.7% 的注意力分数流向首 token；加 SDPA 输出 gate 后约为 4.8%。只在 V 处加门控虽能压低大激活，但 attention sink 仍较明显，支持“抑制激活”和“消除 sink”并非同一机制。论文的解释是稀疏、query-dependent 的 G1 gate 可直接抑制当前 query 不需要的上下文信息；这是实验支持的机制解释，不是对 sink 成因的完整理论证明。

## 实验与主要结果

- 在 15B 总参数、约 2.54B 激活参数的 MoE 模型上，作者比较 30 多种变体。SDPA 后逐维 sigmoid 门控相较基线平均 PPL 从 6.026 降到 5.761，MMLU 从 58.79 升至 60.82；headwise 门控参数更少，也有稳定收益。
- 在 1.7B dense 模型上，门控降低训练 loss spike，并在参数量匹配时改善多项评测。48 层、400B token 的实验中，baseline 在最大 LR `8e-3` 发散，而 SDPA elementwise gate 在该 LR 下完成训练；在 1T token、大 batch 设置中也显示类似稳定性收益。
- 使用 YaRN 将上下文扩展到 128k 后，RULER 上的 gated 模型比 baseline 更稳健。论文报告 64k/128k 上 gated 结果明显较好，但扩展后原有长度范围内两类模型都发生退化，门控只是减轻而非消除该退化。
- 论文报告门控带来的 wall-time latency 增幅低于 2%。

## 结论与边界

这篇论文的重点不是“给注意力分数加权”，而是在 SDPA 输出张量上增加一个由当前 token 状态计算的逐头门控。其作用可从两个方面理解：在 `W_V` 和 `W_O` 之间插入非线性，提升低秩注意力映射的表达力；用 head-specific、query-dependent 的较小 sigmoid 分数产生稀疏输出，减少无关上下文和 attention sink。具体收益依赖 gate 的位置、是否按头区分及训练配置。

论文主要是大规模实证与消融分析。作者承认非线性对训练动力学的整体影响尚未充分解释，也没有严格理论说明 attention sink 如何影响长度泛化。结果来自特定 Qwen 团队训练配方、数据与硬件环境，不能仅凭机制推断所有模型都会获得同等增益；应用时应同时检查长上下文行为、训练稳定性和实际吞吐。

## 延伸问题

- G1 gate 学到的维度稀疏与 headwise gate 的头级缩放，分别对应哪些可解释的上下文过滤行为？
- gate 与 softmax 注意力概率、残差分支、RMSNorm 的相互作用如何影响训练稳定性？
- 在推理时，门控是否能与 SDPA kernel 融合，真实延迟和显存开销是否仍低于 2%？
- attention sink 被压低后，模型在流式生成、前缀缓存和不同位置编码扩展下是否都更稳健？

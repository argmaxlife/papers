# DINO：自监督 ViT 的涌现特性

> **论文**：Mathilde Caron 等，*Emerging Properties in Self-Supervised Vision Transformers*，arXiv:2104.14294v2（2021-05-24）。  
> **原文**：[arXiv:2104.14294](https://arxiv.org/abs/2104.14294)  
> **关键词**：自监督学习、self-distillation、Vision Transformer、teacher EMA、无监督物体分割。

## 一句话概括

DINO（Distillation with NO labels）把自监督学习写成 teacher/student 之间的交叉视图知识蒸馏：同一图像的不同增强视图分别送入 student 和 EMA teacher，student 学着匹配 teacher 的输出分布。方法不依赖标签、负样本、预测器或特殊网络结构；teacher 输出的居中与低温度 sharpening 配合 momentum teacher 避免坍塌。论文发现 DINO 训练的 ViT 在不微调时就有强 k-NN 分类能力，最后一层 attention 还能显露语义区域和物体边界。

## 方法：无标签的自蒸馏

给定图像 `x`，随机增强生成多个视图。student 与 teacher 使用相同网络结构、不同参数。teacher 参数不是反向传播更新，而是 student 参数的指数滑动平均。teacher 只处理两个 global crops；student 处理 global 和 local crops，从而学习 local-to-global 对应关系。

### 从 logits 得到目标分布

网络投影头输出 `K` 维 logits。设 student 输出 `z_s=g_{θ_s}(x)`，teacher 输出 `z_t=g_{θ_t}(x)`，teacher 的中心向量为 `c`。概率分布为：

$$
p_s^{(k)}(x)=\frac{\exp(z_s^{(k)}(x)/\tau_s)}{\sum_{j=1}^K\exp(z_s^{(j)}(x)/\tau_s)},
$$

$$
p_t^{(k)}(x)=\frac{\exp((z_t^{(k)}(x)-c^{(k)})/\tau_t)}{\sum_{j=1}^K\exp((z_t^{(j)}(x)-c^{(j)})/\tau_t)}.
$$

`τ_s`、`τ_t` 是 student 和 teacher temperature。较小的 `τ_t` 让 teacher 分布更尖锐；`c` 通过 batch 统计更新，减轻某些输出维度长期占优。

### 跨视图交叉熵

对每个 teacher global view `x_g`，让 student 匹配其他视图 `x'` 的 teacher 分布：

$$
L=\sum_{x_g\in\{x_g^1,x_g^2\}}\;\sum_{x'\in V,\;x'\ne x_g}
-\sum_{k=1}^K p_t^{(k)}(x_g)\log p_s^{(k)}(x').
$$

举例：一个 batch 有 `B=2` 张图，每张产生 2 个 `224×224` global crop 和 8 个 `96×96` local crop。teacher 只算两个 global views；student 算全部 10 个 views。若 projection head 输出 `K=65536` 个 logits，单个 global teacher view 的目标张量是 `[B,K]=[2,65536]`；它分别监督同一图像的其他 9 个 student views（不和同一个输入 view 配对）。teacher 分布 stop-gradient，梯度只更新 student。

teacher 权重和中心按 EMA 更新：

$$
\theta_t\leftarrow\lambda\theta_t+(1-\lambda)\theta_s,\qquad
c\leftarrow m c+(1-m)\,\mathrm{mean}_{batch}(z_t).
$$

`λ` 是网络 momentum，训练中逐渐接近 1；`m` 是 center momentum。中心是 logits 维度上的 batch 均值，不是对图像特征做中心化。teacher 的渐进更新减少目标突然变化，也可理解为在参数空间对过去 student 做平滑集成。

## 为什么不坍塌

若所有输入都映射成同一输出，student 和 teacher 仍可能“互相一致”，所以只做匹配并不足够。DINO 使用两种互补操作：

- **Centering**：从 teacher logits 中减去运行中心 `c`，避免某个 prototype 维度垄断输出。单独居中可能促使所有维度趋于均匀分布，也是一种坍塌。
- **Sharpening**：使用较低的 teacher 温度 `τ_t`，让目标分布更尖锐，抵消均匀化趋势。单独 sharpening 则可能让所有样本坍到同一维度。
- **Momentum teacher**：平滑 teacher 目标，在训练过程中提供较稳定、且滞后于 student 的目标分布；它与居中和 sharpening 一起构成稳定训练的重要条件。

论文消融显示，在 ViT 设置中去掉 momentum teacher 会导致方法失败；居中与 sharpening 的组合可以只用简单 cross-entropy 工作，不必引入负样本、predictor 或额外归一化模块。多裁剪则显著改善特征质量，但它是性能组件，不应与防坍塌机制混为一谈。

## ViT 为什么表现特别好

论文强调几个组成因素：

1. **小 patch**：patch 从 16×16 减到 8×8 时，token 数增加，空间细节更丰富。ViT-B/8 比 ViT-B/16 在 ImageNet 线性评估由 78.2% 提升到 80.1%，k-NN 从 76.1% 到 77.4%；代价是吞吐下降和显存需求上升。
2. **Multi-crop**：两张 global view 学整体语义，多个 local view 迫使局部 crop 对齐到 teacher 的全局语义。它在 DINO 中同时提高精度和计算效率，因为小 crop 的 token 数较少。
3. **自注意力可视化**：最后一层 `[CLS]` query 对 patch 的 attention heads 常自动聚焦不同物体或语义区域；简单阈值化 attention map 即可得到有意义的无监督分割结果。该 attention map 并未通过分割损失训练。
4. **k-NN 特征质量**：DINO ViT 的 k-NN 分类与线性分类差距较小，说明语义类别在冻结特征空间中已较好聚集，不完全依赖学习一个线性分类头。

## 实验结果

- **ImageNet**：ViT-S/16 线性评估 77.0%、k-NN 74.5%；ViT-S/8 达到 79.7% 线性、78.3% k-NN；ViT-B/16 为 78.2%/76.1%，ViT-B/8 达到 80.1%/77.4%（分别为线性/k-NN）。
- **ResNet-50**：DINO 达到 75.3% 线性评估、67.5% k-NN，与当时同架构自监督方法竞争力相当，说明算法并不限于 ViT。
- **图像检索**：冻结 DINO 特征在 Oxford/Paris landmark 检索上优于相应监督预训练特征；在 Google Landmarks v2 上训练的 DINO 特征表现尤其好。
- **视频对象分割**：不微调网络，直接以跨帧最近邻传播 patch 特征。在 DAVIS 2017 上 ViT-B/8 得到 `J&F=71.4`，ViT-B/16 为 62.3，显示小 patch 对空间任务更重要。
- **语义区域发现**：DINO ViT 的最后层 attention map 与目标分割区域有较强一致性，监督 ViT 在杂乱背景中的 attention 定位较弱。

## 阅读结论与局限

DINO 的简洁之处在于把训练目标、teacher 稳定性和增强策略组合起来：预测 EMA teacher 的软目标，student 跨视图学习不变性，teacher 居中与 sharpening 保持非坍塌分布。它也揭示 ViT 自监督特征可能自然形成空间语义结构，后来许多视觉基础模型沿用了类似的 teacher-student 自蒸馏范式。

论文的分割发现主要是定性观察和 attention map 阈值评估，并不意味着模型已学会完整、边界精确的通用分割器。ImageNet 上的 k-NN、线性探测和 DAVIS 实验各自有特定设置，不能直接代表所有下游域。小 patch 虽改善空间特征，也显著增加 token 数与注意力计算；高分辨率部署需要权衡资源。

## 延伸问题

- center 的 batch 统计在小 batch、跨设备训练或分布变化时如何影响 teacher 目标？
- teacher 温度、EMA momentum 与 multi-crop 的最佳组合是否会随模型规模和数据域变化？
- attention map 的物体区域特性如何转化为可靠的检测或分割预测，而不只用于可视化？
- 后续 DINOv2、DINOv3 如何在保留 DINO 全局语义的同时强化 patch-level 特征？

# DINOv3：大规模自监督视觉特征与 Gram Anchoring

> **论文**：Oriane Siméoni 等，*DINOv3*，技术报告，arXiv:2508.10104v1（2025-08-13）。  
> **原文**：[arXiv:2508.10104](https://arxiv.org/abs/2508.10104)  
> **关键词**：自监督学习、视觉基础模型、Gram anchoring、稠密特征、蒸馏。

## 一句话概括

DINOv3 将 DINOv2 式自监督训练扩展到约 7B 参数和 1.689B 张策展图像，并解决长时间训练时常见的局部 patch 特征退化问题。核心新增方法是 Gram anchoring：让当前模型 patch 特征之间的相似度矩阵贴近早期模型（或其高分辨率平滑版本），从而保住局部一致性，同时让全局语义特征继续学习。随后作者做高分辨率适配，并将 7B teacher 蒸馏为 ViT、ConvNeXt 等实用规模模型。

## 问题背景

DINOv2 证明自监督视觉模型可以在没有图文配对的情况下提供强通用特征，但把模型和训练时长继续扩大后，出现了一个全局与局部目标之间的张力：ImageNet 分类等依赖全局语义的结果持续变好，分割、深度、匹配等依赖 patch 特征的任务却在训练约 200k 次后开始下降。patch 之间的 cosine similarity map 也越来越噪，说明相似区域的局部表示不再稳定。

这与 DINOv2 registers 论文讨论的高范数异常 token 不同。DINOv3 使用 register tokens 后，patch 范数保持稳定；这里的问题是 patch 特征的相对关系逐渐变差，表现为 CLS 与 patch 越来越相似、局部性下降。

## 数据与第一阶段训练

### LVD-1689M 数据组合

作者从约 17B 张公开 Instagram 图片池构建训练数据的三部分：

- **聚类均衡集**：用 DINOv2 图像嵌入做五层层次 k-means 和均衡抽样，得到 LVD-1689M，约 1.689B 张图，目标是覆盖长尾视觉概念。
- **检索集**：从原始池中检索与精选 seed 数据集相似的图片，增强常见下游任务相关视觉内容。
- **公开视觉数据**：混入 ImageNet-1k、ImageNet-22k、Mapillary 等数据，保持常用基准上的质量。

训练时每步随机选择两种 batch 之一：10% 是只含 ImageNet-1k 的高质量 homogeneous batch；其余是由其他组件按比例混合的 heterogeneous batch。数据消融显示，单用聚类、检索或原始数据各有偏差，组合方案 LVD-1689M 在多项指标上均衡最好。

### 全局、局部与分布正则目标

预训练沿用 DINOv2 的判别式自蒸馏框架：DINO 在不同视图的 `[CLS]` 表示上对齐 teacher/student prototype 分布；iBOT 随机遮住 student 的 patch，让其预测 teacher 对应 patch 的 latent prototype；teacher 由 EMA 更新。两种目标都使用 Sinkhorn-Knopp 归一化，另加 KoLeo 正则鼓励 batch 特征分布更均匀：

$$
L_{pre}=L_{DINO}+L_{iBOT}+0.1L_{KoLeo}.
$$

架构扩大到 40 层、6.7B 参数的 ViT-7B（约 4096 隐藏维度、32 个 128 维 attention heads、patch size 16，含 4 个 registers）。采用 axial RoPE，并对坐标框做随机缩放 jitter，增强分辨率、尺度和宽高比适应性。主训练使用 2 个 256×256 global crops 和 8 个 112×112 local crops，每图；总 batch 4096、256 张 GPU。作者取消参数调度，warmup 后用固定学习率、weight decay 与 teacher EMA momentum 训练 1M iterations，便于训练时长按需延长。

## Gram Anchoring：修复 patch 关系

设一张图有 `P` 个 patch，输出维度为 `d`。将 student 的 patch 特征逐行做 L2 归一化，得到：

```text
X_S: [P, d]
```

从训练早期选出的 Gram teacher 得到同样形状的 `X_G: [P,d]`。各自沿特征维做点积，得到 patch 两两相似度矩阵：

```text
G_S = X_S @ X_S.T: [P, P]
G_G = X_G @ X_G.T: [P, P]
```

每个矩阵元素 `G[i,j]` 是同一图像第 `i`、`j` 个 patch 的 cosine similarity。论文式 (2) 定义：

$$
L_{Gram}=\left\|X_SX_S^\top-X_GX_G^\top\right\|_F^2.
$$

例如输入图像产生 `P=256` 个 patch、特征宽度 `d=4096` 时，student 和 teacher 特征都是 `[256,4096]`，Gram 矩阵为 `[256,256]`。损失比较 65,536 个 patch 对的关系，而非要求每个 student 特征向量逐维复制 teacher。若所有特征做相同正交旋转 `X_S=X_G R`，且 `RRᵀ=I`，则 Gram 矩阵不变；这说明目标保留几何关系、允许表征坐标系变化。

teacher 取自较早的训练阶段，因为那时 dense feature map 更局部、更干净。作者只在 global crops 上计算，约 1M iteration 后才开启 refinement，以控制额外成本；refinement 总损失为：

$$
L_{Ref}=w_D L_{DINO}+L_{iBOT}+w_{DK}L_{KoLeo}+w_{Gram}L_{Gram}.
$$

Gram teacher 每 10k iteration 更新。作者观察到 Gram 目标开启后，稠密任务在约 10k 步内迅速改善；DINO 全局损失受影响较小，而 iBOT loss 下降更快，表明 Gram anchoring 特别有助于 patch-level 训练信号。

### 高分辨率 Gram teacher

进一步的 `L_HRef` 让 Gram teacher 输入为 student 的两倍分辨率，得到更细的 feature map，再对 teacher 特征图做 2× 下采样以匹配 student patch 网格，最后比较对应 Gram 矩阵。这把高分辨率 teacher 更平滑、更稳定的局部相似结构蒸馏给 student。实验中，ViT-7B 的 ADE20K mIoU 从基础模型约 50.3 经普通 Gram 提升至 53.6；使用高分辨率 Gram 后达到 55.7。早期 100k/200k teacher 效果接近，使用已经退化的 1M teacher 则更差。

## 后训练与模型家族

- **分辨率适配**：主训练在 256 分辨率附近，之后用 512/768 global crops 和多种 local crop 尺寸再训练 10k iteration，并继续使用 Gram anchoring。特征能稳定泛化到训练分辨率以上，论文展示最高 4096 级输入。
- **多学生蒸馏**：冻结 ViT-7B teacher，以相同 DINO/iBOT/KoLeo 目标训练多个学生，不使用 Gram loss。作者设计共享 teacher 推理的并行流程，同时蒸馏多个大小的学生，减少重复 teacher 成本。
- **模型选择**：ViT-S 21M、S+ 29M、B 86M、L 300M、H+ 840M；另有多个 ConvNeXt 尺寸，适合不同设备和量化部署。ViT-H+ 虽比 7B 小近一个数量级，多个指标仍接近 teacher。
- **文本对齐**：另行训练与 dino.txt 类似的图文对齐变体，为 DINOv3 增加 zero-shot 分类/检索能力；该步骤与纯自监督主模型区分开。

## 主要结果

以下指标来自冻结 backbone 上的轻量评估或冻结 backbone 加任务 decoder，不能一概视为纯线性探测：

- **稠密特征**：ViT-7B/16 冻结特征线性评估，在 ADE20K 达到 55.9 mIoU、Cityscapes 81.1、VOC 86.6；NYUv2 深度 RMSE 0.309、KITTI 2.346。3D keypoint correspondence recall 在 NAVI/SPair 为 64.4/58.7，TokenCut 无监督 object discovery 在 VOC07/VOC12/COCO 为 66.1/69.5/55.1。
- **复杂任务头**：冻结 ViT-7B 加 Plain-DETR，在 COCO detection 达到 66.1 mAP；冻结 backbone 加 ViT-Adapter/Mask2Former，在 ADE20K 达到 63.0 mIoU。主干无需为这些任务微调，但 decoder 使用了任务数据训练。
- **全局表征**：ImageNet 线性评估 88.4 Top-1，ImageNet-R 91.1、Sketch 71.3、ObjectNet 79.0；iNaturalist 2021 线性评估 89.8。实例检索中 Oxford-H、Paris-H、Met 和 AmsterTime 均表现强。
- **模型家族**：DINOv3 ViT-L 在 ADE20K 为 54.9 mIoU，对比同规模的 DINOv2 为 48.8；深度、tracking 和匹配等任务也普遍提升。ConvNeXt 学生在高分辨率和 dense 任务上优于论文比较的监督 ConvNeXt。
- **卫星领域**：把同一 recipe 用于 493M 张卫星图像 SAT-493M。卫星专训 7B 在 canopy height 的 SatLidar val/test MAE 为 2.2/3.2，Open-Canopy 为 2.02；在 15 个地理分类、分割、检测任务中，冻结 web/satellite 模型在 12 项创下当时最佳结果。
- **训练成本**：论文估计 ViT-7B 1M steps 训练约 61,440 H100 GPU-hours、47 MWh、18 tCO₂e（估算按指定 PUE 和电网碳强度，未含制造、冷却等其他排放）。

## 结论与局限

DINOv3 的主要新意不是单纯堆大模型，而是承认全局语义与局部一致性在长训中会拉扯，并用 Gram 关系监督给 dense features 一个独立锚点。实验表明，早期模型能提供优质局部结构，后期主模型则拥有更强全局语义；Gram anchoring 将两者结合，使扩展训练不再以稠密特征退化为代价。

结果仍需结合数据和资源背景理解：主模型依赖大规模 Instagram 数据和约 61k H100 GPU-hours；数据来源与 seed 选择会塑造覆盖面。7B 冻结 backbone 的下游系统虽减少主干微调，仍可能训练大型 decoder 和使用额外标注数据。卫星实验也显示，物理测量任务受益于领域专训和传感器统计匹配。技术报告的比较涉及不同数据、分辨率和评测协议，跨论文数字不总是完全可比。

## 延伸问题

- Gram teacher 的最佳训练阶段为何是早期？是否能用任务无关的指标自动选择 teacher checkpoint？
- 维持 patch 两两 cosine 结构是否会限制模型学习真正有用的新局部语义，还是只要保留关系就足够？
- 不同分辨率、patch size 或宽高比下，Gram anchoring 的计算和显存成本如何扩展？
- 大规模自监督模型在更广的文化、地理和成像条件下，如何建立可审计的数据覆盖与偏差评估？
